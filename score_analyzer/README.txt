--- How to use ---

1. Run the script.
2. Enter student scores separated by spaces when prompted.
3. The script will display a report with the average, highest, lowest scores, and pass rate.

--- sample run ---
Enter student scores separated by spaces: 85 90 78 92 88
Average score: 86.6
Highest score: 92
Lowest score: 78
Pass rate (>= 60): 100.0%
